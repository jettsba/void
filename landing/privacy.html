что обрабатывает void и чего здесь нет.

обновлено 25.10.2026

чего здесь нет

нет аккаунтов, email, паролей. нет истории сообщений и звонков. нет cookies-трекеров, аналитики, рекламных партнёров. void не продаёт данные и не передаёт их третьим лицам — нечего передавать.

что обрабатывается

сервер видит IP-адрес твоего устройства — это технически необходимо для установления соединения и для защиты от атак (лимиты, защита от перебора кодов). IP хранится только в оперативной памяти сервера — не дольше часа, на диск не пишется и никуда не передаётся. в логах вместо него — анонимная метка, которая меняется каждые сутки; коды комнат и id участников туда тоже попадают только метками.

пока ты в комнате, в памяти сервера лежит твой ник — чтобы показать его собеседникам. вышел — ник забыт.

что остаётся у тебя в браузере

localStorage хранит твои настройки: язык, ник, выбор микрофона и динамика, уровни громкости. они нужны только твоему браузеру, чтобы запомнить выбор между сессиями; на сервер из них уходит только ник — и только на время звонка. следов разговоров в браузере не остаётся. удалить настройки можно очисткой данных сайта.

как идёт разговор

голос, чат и файлы передаются напрямую между участниками через WebRTC. сервер только помогает вам найти друг друга в начале (это называется signalling) — дальше он не участвует. весь контент шифруется протоколами DTLS-SRTP, у сервера нет ключей.

проверить, что посередине никто не встал — даже сервер, — можно по коду безопасности: пять символов в комнате. совпали у всех — разговор только ваш. сверяйте вслух, а не в чате.

чтобы найти прямой путь, браузер спрашивает свой внешний адрес у публичных STUN-серверов (google, cloudflare) — так работает WebRTC. они видят только IP, разговор через них не идёт.

когда возникает relay

иногда прямое соединение между участниками невозможно — обычно из-за корпоративных сетей или мобильных операторов с CG-NAT. так бывает примерно с каждой третьей парой: тогда зашифрованные пакеты проходят через наш relay-сервер (TURN). он видит только метаданные подключения: IP-адреса обеих сторон и длительность сессии — под одноразовым id, без ника и без кода комнаты. relay доступен только участникам комнаты. контент остаётся зашифрованным — relay не может расшифровать голос или сообщения, ключи только у вас и собеседника.

если ты отправляешь отчёт об ошибке

отчёт уходит, только когда ты сам нажмёшь «отправить» в настройках, — на почту разработчика. в нём: твоё описание, контакт (если указал), версия, браузер и технический журнал приложения. код комнаты и id участников заменяются анонимными метками, IP — суточной меткой.
