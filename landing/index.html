антивирус блокирует установку?

void вышел в релиз недавно, и установщик пока не подписан сертификатом разработчика — его выдача занимает время. а без подписи windows судит о файле не по содержимому, а по репутации: сколько людей его уже скачали и запустили.

у свежей сборки репутации еще нет — поэтому «обнаружен вирус» получает почти каждый новый exe, даже полностью чистый.

проверить можно самостоятельно:

отчет virustotal исходный код на github
как установить
  1. — 01 браузер пишет «обнаружен вирус» → открой список загрузок, нажми «···» рядом с файлом и выбери «сохранить всё равно».
  2. — 02 при запуске появилось окно «windows защитила ваш компьютер» → нажми «подробнее», затем «выполнить в любом случае».
  3. — 03 если defender уже удалил файл → «безопасность windows» → «защита от вирусов и угроз» → «журнал защиты» → найди void и нажми «разрешить на устройстве».
